## Известные ограничения

Изображения из буфера не восстанавливаются после cold restart (backlog выше;
подтверждено также на прежнем коде). Per-thread cwd для списка панелей bridge не предоставляет.
Облачная история и session picker VS Code не фильтруются. Unknown версии не
патчуются автоматически. Другие клиенты не наблюдаются. Sandbox/auth/history/
права доступа/история не изменяются; автозапуска задач и собственного чата нет.

Новые функции сверх принятого этапа требуют нового запроса пользователя.
