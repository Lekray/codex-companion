## Открытые чаты

`Codex: Открытые чаты` доступна в палитре, вверху редактора и в меню квот.
Список показывает названия и состояния открытых панелей текущего окна. Ожидание
ввода и ошибки идут первыми. Поиск по названию сохраняется при обновлении списка;
разные представления одного чата различимы. Выбор переводит фокус в существующую
панель. Закрытая панель не переоткрывается.

Список использует метаданные официального расширения текущего окна. Отдельного
наблюдения за другими клиентами и облачными задачами нет; строгой фильтрации
каждого открытого thread по cwd здесь нет. Фильтр штатной локальной истории
по проекту действует отдельно.

Доступны команды `codexCompanion.nextWaitingChat` (следующая ожидающая панель) и
`codexCompanion.nextAttentionChat` (сначала ожидание, затем ошибки). Их можно
назначить на клавиши, привязок по умолчанию нет. Счётчик `[? N]` показывается
только при N > 0 и обновляется по событиям текущего окна, без постоянного опроса;
он не зависит от дедупликации уведомлений. Перед переходом личность существующей
панели сверяется двумя чтениями состояния; закрытая панель не переоткрывается.

## Раздельные текстовые черновики

Новые вкладки, открытые Companion, начинают с пустого поля и сохраняют собственный
текст при переключении и после перезапуска. Проверено в настоящем VS Code на
26.1007.21434 и 26.1021.22027. Сохранённые чаты и
проектная пара модель + effort сохраняют прежнее поведение.

Прежний общий черновик сохранён. Открыть его можно командой
`Codex: Открыть прежний общий черновик`. Автоматического копирования общего
текста во все новые вкладки нет.

Изображения из буфера не смешиваются между открытыми вкладками, но после
перезапуска не восстанавливаются. То же поведение подтверждено на прежнем
неизменённом коде; в 0.2.6 восстановление не реализовано. Исследование показало,
что изображение живёт в памяти отдельно от сохраняемого текста, поэтому нужен
отдельный нативный target — задача следующего этапа.

Для 26.1007.21434 исправление меняет одну ветку выбора ключа HOME composer (`Fv`);
для 26.1021.22027 тот же `scopeKey` встроен в chunk `composer-scope`. Нативные
хранилища `composer-prompt-drafts-v2` и `composer-retained-documents-v1` получают
стабильный ключ с UUID вкладки. Специальная нативная блокировка `homeDraftKey`,
ключи сохранённых чатов, identity, отправка сообщений и выбор модели не менялись.
В старом билде helper добавляется перед двумя модулями; в новом — prefix в
`composer-scope`. Вариант `Fv`/`7a` относится только к 26.1007.

## Квоты

В строке состояния сохранён логотип Codex. Показаны два наиболее израсходованных
фактических окна сервера, остальные обозначены `+N`. В подсказке и отчёте есть
все окна, использование и остаток, точные кредиты, время сброса с UTC-смещением
и время обновления. Предупреждения 90% / 100% действуют только для свежих данных.
Кредиты теперь показываются рядом с лимитами; в нижней кнопке баланс округляется до целого, а в подсказке и отчёте остаётся точная строка сервера.

Прошедший сброс помечается как требующий обновления; расход не обнуляется
предположением. Прежняя приблизительная оценка темпа с начала окна сохранена и
скрывается для несвежих данных. Длительности берутся из сервера. Разбивки расхода
по чатам или проектам нет. App Server Companion используется только для квот.
История/сэмплирование квот не реализованы: следующий этап — только account-wide
с границами reset/аккаунта, без оценок по проектам.
Поля сверены с [официальной документацией](https://learn.chatgpt.com/docs/app-server).

## Сохранённые возможности

- Каждый клик по кнопке OpenAI вверху редактора открывает официальную вкладку.
- Штатное переименование чата сразу меняет название вкладки.
- Последняя успешная явная пара модель + effort запоминается для проекта.
- `[~]` — работа, `[V]` — успешное завершение, `[!]` — ошибка, `[?]` — ожидание.
- В 26.1021.22027 карточки асинхронных вопросов включают `[?]`; завершение ответа
  Codex сохраняет ожидание без `[V]`, пока карточка ожидает ответа пользователя.
- При переходе idle → waiting показывается уведомление «нужен ваш ответ»
  (`needs your answer` в английском UI) с отдельным коротким синтезированным
  сигналом `waiting.wav` (0.32 с); прежний звук завершения не менялся.
- Прежние настройки уведомлений, окон и звука сохранены; mute действует на оба
  сигнала. Дедупликация по-прежнему логическая (`eventId`): отдельного уведомления
  на каждый вопрос внутри одного turn не гарантируется, replay/snapshot молчат.
- Однократный звук на новый `[V]`; восстановление вкладок молчит.
- История проекта и обновление названия используют единый проверенный список
  версий (VERIFIED_EDITOR_VERSIONS) для 26.1007.21434 и 26.1021.22027.
- История локальных recent/full/search официальной панели фильтруется по проекту.

Своего чата нет. Кнопка refresh title удалена; резервная команда палитры сохранена.

## Установка, проверка и откат

Команды палитры:

- `Codex: Установить / обновить дополнения Companion`
- `Codex: Восстановить исходные файлы Codex`
- `Codex: Проверить совместимость Codex`

Из папки проекта:

```powershell
npm run patches:check   -- --extension ((code --locate-extension openai.chatgpt).Trim())
npm run patches:install -- --extension ((code --locate-extension openai.chatgpt).Trim())
npm run patches:restore -- --extension ((code --locate-extension openai.chatgpt).Trim())
```

CLI: `node scripts/companionPatches.cjs check|install|restore --extension DIR`.
Проверка ничего не записывает. Установщик проверяет все цели до записи, блокирует
конкурирующие операции, пишет атомарно и откатывает свои изменения при ошибке.
Неизвестные версии, смешанные/изменённые байты и повреждённые backup не исправляются
автоматически; внешние изменения сохраняются, неполный откат сообщается явно.

Для 26.1007.21434 сохранены прежние пять целей, metadata schema 1/2 и backup
`%LOCALAPPDATA%/codex-companion/patches/26.1007.21434/drafts-v1`.
Для 26.1021.22027 используется schema 3 и одиннадцать оригиналов: package.json,
out/extension.js, прежние восемь webview chunks и app-initial-13f932cb2f13.js.
Точный набор и hash — resources/patchBundleManifest-26.1021.22027.json;
attestation — resources/patchAttestation-26.1021.22027.json. Новый backup —
`%LOCALAPPDATA%/codex-companion/patches/26.1021.22027/chunks-v3`.
Старые chunks-v2/chunks-v1 и legacy backup сохраняются.

При переходе с 0.2.9 прежний engine сначала точно восстанавливает десять
оригиналов, затем engine 0.2.10 устанавливает одиннадцать целей. Это не разрешает
перезаписывать неизвестные байты. Полный native-откат новым engine возвращает
все одиннадцать исходных файлов; данные и Companion не удаляются. Downgrade
самого пакета Companion после перехода уведомлений на SQLite требует отдельной
миграции отметок: старая версия эту БД не читает.

После задач выполните один `Developer: Reload Window`. Автоматического reload,
закрытия окон и возобновления задач нет. Хранилище уведомлений переключится после
обычного полного перезапуска VS Code; перезапускать приложение немедленно не нужно.
Пакет — `.artifacts/codex-companion-0.2.10.vsix`. Публикации нет.
